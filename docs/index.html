RimWorld 1.6 magic systems

Magic Framework

A modular, data-driven spell framework for RimWorld, built for authored spells, reusable action primitives, persistent magical effects, and content packs that can grow without rewriting core systems.

Get Started Explore Mods

Framework

Data-first spell authoring for colonies that want stranger tools.

Composable Actions

Damage, healing, hediffs, explosions, terrain changes, summons, teleports, projectiles, chains, force fields, and sustained buffs are authored through XML action trees.

Persistent Runtime State

Area zones, wall zones, spawned things, summons, maintained shields, delayed actions, and proximity triggers survive normal gameplay flow and save/load boundaries.

Targeting Tools

Reusable queries support radius searches, nearest valid targets, shape targets, directional chains, deterministic ordering, limits, and explicit self-affect policies.

Procedural FX

Element, delivery, effect shape, power tier, sounds, flecks, colors, and override metadata combine into extensible magic visuals for new spell families.

For Mod Authors

Use Magic Framework as a spell runtime, not just a content pack.

External mods can define new spells by composing framework action defs, costs, requirements, targeting policies, lifecycle hooks, power scalars, procedural FX metadata, and reusable target queries.

MF Vanilla doubles as starter content and as a working reference library for XML patterns such as scroll learning, school research gates, maintained spells, terrain magic, chain effects, displacement, and persistent hazards.

First Spell Minor Heal Start with direct targeting, mana, cooldown, and immediate healing. Projectile Ember Bolt Learn projectile launch and impact action authoring.
