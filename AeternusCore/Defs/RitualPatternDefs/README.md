# Ritual Notes

## Rite of Priestly Devotion

Requirements:

- Pawn holds a priestly role.
- Pawn follows Faith of Aeternus.
- Shrine belongs to a valid patron or domain.
- Optional offering cost.

Result:

- Removes previous devotion marker.
- Applies new devotion marker based on altar.
- Adds obligations.
- Enables hidden benefit or miracle events.
- Influences colony favor gain.

## Bonewright Ritual Roll

```text
Ritual Score =
Bonewright skill
+ relevant stats
+ chamber quality
+ Spikecore sanctity
+ offerings
+ colony favor
+ priest devotion
- corpse instability
- room taint
- void leakage
- emotional unrest
```

Outcome bands:

- Great success: stronger undead, stable memory, named revenant retains personality, chamber gains sanctity.
- Success: expected undead created.
- Imperfect success: undead created with flaw, minor instability, chamber gains minor taint.
- Failure: Hollowborn, hostile spirit, haunting, or chamber taint increase.
- Catastrophic failure: Dreadrot, Echobound, void breach, priest injury, or major Spikecore corruption.
