# Hediff Notes

Use hidden hediffs or hediff comps for devotion and spiritual state where possible.

Planned marker categories:

- Patron devotion markers.
- Bonewright ritual strain.
- Spiritual corruption.
- Grave taint exposure.
- Blessing aftermath.
- Spirit attachment or haunting pressure.

Devotion should not appear as a normal trait. It should behave like hidden state that shrine, ritual, favor, and incident systems can query.
