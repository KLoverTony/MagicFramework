# Incident Notes

Blessings should feel like mysterious events, not predictable permanent stat buffs.

Examples:

- Terra: blight weakens, crops recover, animals calm, rare fertile soil appears.
- Umbra: graves become still, restless dead quiet, grief resolves faster after proper rites.
- Luminara: disease stabilizes, downed pawn survives unexpectedly, healer inspiration.
- Lunaria: prophetic dream, psychic drone resistance, nighttime threat omen.
- Aether: caravan speed miracle, storm disperses danger, lightning strikes enemies during crisis.

Use hidden favor, shrine state, priest devotion, ritual history, and room sanctity as incident weights.
