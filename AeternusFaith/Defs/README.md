# Aeternus Faith Def Notes

This directory is reserved for playable RimWorld Defs. Use the `AF_` prefix for new Def names.

Planned groups:

- `IdeoDefs`: Faith of Aeternus, Corrupted Six, role definitions, and ideology structure.
- `PreceptDefs`: burial, remembrance, sacred space, magic acceptance, corruption hostility.
- `ThingDefs/Buildings/Shrines`: deity or domain shrine buildings.
- `ThingDefs/Buildings/Floors`: Spikecore floor variants.
- `RitualPatternDefs`: devotion, funerary, purification, and Bonewright rituals.
- `HediffDefs`: hidden devotion markers, ritual instability, corruption, spiritual residue.
- `IncidentDefs`: blessings, omens, hauntings, and divine intervention events.
- `ThoughtDefs`: subtle mood reactions from rites, graves, spirits, and sacred rooms.
- `ResearchProjectDefs`: optional gates for Bonewright, Spikecore, and shrine progression.

Avoid adding partially valid XML Defs until each feature is ready to test in game.
