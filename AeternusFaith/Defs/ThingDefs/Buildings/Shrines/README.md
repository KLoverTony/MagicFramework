# Shrine Notes

Shrines represent gods, god-pairs, or divine domains.

Possible domains:

- Light and Shadow: Luminara / Umbra
- Sun and Moon: Solariel / Lunaria
- Land and Sky: Terra / Aether
- Wisdom and Civilization: Astraeus / Eudora
- Wild and Spirit: Aethra / Sylvanor
- Corruption / Void: Corrupted Six counterpart

Each shrine should eventually support:

- Stored favor.
- Sanctity.
- Corruption state.
- Priest-only Rite of Priestly Devotion.
- Destruction or desecration consequences.
- Hidden blessing event hooks.
