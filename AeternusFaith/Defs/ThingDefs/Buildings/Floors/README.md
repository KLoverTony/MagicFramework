# Spikecore Floor Notes

Spikecore plates define Bonewright ritual room identity and hidden spiritual condition.

Planned variants:

- Ossanith Spikecore: safer skeletal rites, preservation, reduced fallout.
- Animara Spikecore: memory retention, soul echo stability, ancestor communion.
- Voressai Spikecore: powerful rituals, higher corruption risk, void and entropy effects.

Hidden room values:

- Taint
- Resonance
- Sanctity
- Memory residue
- Void leakage

Room examples:

- Mostly Ossanith: Ossan Sanctum.
- Mostly Animara: Hall of Echoes.
- Mostly Voressai: Entropy Chamber.
- Mixed Ossanith and Animara: Chamber of Reverent Silence.
- Mixed Animara and Voressai: Hall of Fractured Echoes.
